1 · Hover a session row and open its ⋯ menu.

2 · Choose Expose session — a bridge is minted for exactly that session.

3 · A handoff prompt lands on your clipboard. No token to copy.

4 · Paste it into Codex / Trae. The URL is the credential.

5 · The Agent reads /info → /transcript → /pending, and sees the question.

6 · It answers with POST /answer — the session resumes — then reports back and stops.

Why it is built this way

Two traps this plugin exists to avoid.

⇄

Its own listener

DSH's web server answers an outside caller with 404 outside /api and 401 unauthorized inside it. So the bridge runs its own node:http listener on loopback, and the URL carries the capability.

✓

A real self-check

Before handing over a prompt, /expose fetches its own URL over a real TCP socket. If it is not 200, no prompt is copied — you get the status code instead of a dead link.

■

It tells the Agent to stop

The prompt is explicit: read, report, stop. Do not hunt for the auth implementation, guess other URLs, or scan ports — that is a dead end that burns tokens.

API

Everything is reachable with curl. No cookie, no header, no token.

RouteMethodPurpose
/session-bridge/expose?sessionId=…GETmint (or reuse) an exposure; returns the discovery document + prompt
/session-bridge/info?bridge=…GETdiscovery document — cwd, model, seq, endpoints
/session-bridge/status?bridge=…GETlive? running? current seq
/session-bridge/transcript?bridge=…&since=NGETthe conversation, incrementally
/session-bridge/pending?bridge=…GETthe pending question with its options, or null
/session-bridge/answerPOST{ bridge, callId?, answers:[{ id, selected:[label], custom? }] }
/session-bridge/commandPOST{ bridge, line: "/compact" }
/session-bridge/revoke?bridge=…GETdrop one exposure

Cursor contract: send the seq from one response back as the next request's since. snapshotEvents is half-open and session.seq is the next offset — no +1, no guessing.

Install

Paste this into DeepSeek Harness. It installs the plugin from GitHub and stars the repo.

The block below is in Chinese on purpose — it is the text you paste into the Harness. The rest of this page is English.

install-prompt.txt 
请把 DeepSeek Harness 插件 `dsh-session-bridge` 从 GitHub 安装到当前 profile，并给这个仓库点一个 star。

仓库地址：https://github.com/OWNER/dsh-session-bridge

1. 先读仓库的 README，然后按当前 profile 安装第三方 bundle 的**正规方式**安装它。
   桌面 profile 走插件管理器的 bundle 安装，不要手工改 profile 的配置文件。
2. 验证：左侧会话栏任意会话行的 "..." 菜单里应多出一行。
   如果插件管理器报 "did not activate"，立刻停下并把完整报错发我，不要自己猜着改配置。
3. 安装成功后，在 GitHub 上给这个仓库点 star（例如
   `gh api -X PUT /user/starred/OWNER/dsh-session-bridge`），并告诉我 star 是否成功。

不要 push、不要发布、不要开 PR，除非我明确要求。

Replace OWNER with the GitHub account hosting the repository. Restart DSH after the first install: the Host half is a Node module and is not reliably hot-reloaded.
